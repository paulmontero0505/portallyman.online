# Módulo EVADES Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir el módulo EVADES completo: cálculo automático de las 10 competencias a partir de `incidencias`/`reconocimientos`/`evaluacion_desempeno` existentes, formulario de revisión/ajuste con motivo obligatorio, listado con KPIs, y exportación a PDF.

**Architecture:** Catálogo fijo en código (`includes/evades_catalogo.php`) + motor de cálculo puro que recibe `$conn` (`includes/evades_engine.php`) + 4 endpoints JSON (`api/*_evades.php`) + una página (`pages/evades.php`) con el mismo lenguaje visual y patrón JS que `pages/evaluacion_desempeno.php`. Tres tablas nuevas: `evades_evaluaciones`, `evades_competencias`, `evades_historico`.

**Tech Stack:** PHP 7+ / mysqli, MySQL/MariaDB, JS vanilla (sin build step), jsPDF + jspdf-autotable (CDN, ya cargado en el patrón existente).

```php
/** true si la competencia tiene algún lado (incremento o descuento) automatizado. */
function evades_tiene_automatizacion($competenciaKey) {
    $cat = evades_competencias();
    if (!isset($cat[$competenciaKey])) return false;
    $c = $cat[$competenciaKey];
    return $c['rec_competencia'] !== null || $c['inc_competencia'] !== null;
}

/**
 * Matriz Frecuencia (1-5) × Impacto → puntos de descuento.

/**
 * Rango de fechas [inicio, fin] de un período 'YYYY-T#'. Null si el
 * formato no calza.
 */
function evades_periodo_fechas($periodo) {
    if (!preg_match('/^(\d{4})-T([1-4])$/', $periodo, $m)) return null;
    $anio = (int)$m[1];
    $t = (int)$m[2];
    $meses = [1 => [1, 3], 2 => [4, 6], 3 => [7, 9], 4 => [10, 12]];
    [$mIni, $mFin] = $meses[$t];
    $inicio = sprintf('%04d-%02d-01', $anio, $mIni);
    $fin = date('Y-m-t', strtotime(sprintf('%04d-%02d-01', $anio, $mFin)));
    return ['inicio' => $inicio, 'fin' => $fin];
}

/** Los 4 trimestres de un año, con etiqueta y rango, para poblar el selector. */
function evades_periodos_del_anio($anio) {
    $out = [];
    foreach ([1, 2, 3, 4] as $t) {
        $periodo = "$anio-T$t";
        $out[$periodo] = evades_periodo_fechas($periodo);
    }
    return $out;
}

/** Clasificación EVADES según el puntaje total (0-100). */
function evades_clasificacion($puntaje) {
    if ($puntaje <= 54) return 'Debajo de lo esperado';
    if ($puntaje <= 70) return 'En lo esperado';
    if ($puntaje <= 80) return 'Sobre lo esperado';
    return 'Sobresaliente';
}

/**
 * Filtro de visibilidad SQL para listar evaluaciones EVADES según el rol
 * de la sesión. Se usa contra un alias de `colaboradores` (por defecto
 * 'col') porque coordinador_id vive ahí, no en evades_evaluaciones.
 */
function evades_filtro_visibilidad($aliasColaborador = 'col') {
    $rol = $_SESSION['user_rol'] ?? '';
    $uid = (int)($_SESSION['user_id'] ?? 0);
    if (in_array($rol, ['Administrador', 'Supervisor'], true)) return '1=1';
    if ($rol === 'Coordinador' && $uid > 0) return "$aliasColaborador.coordinador_id = $uid";
    return '0=1';
}
```

### Task 3: Motor de cálculo `includes/evades_engine.php`

**Files:**
- Create: `includes/evades_engine.php`

- [ ] **Step 1: Escribir el motor**

```php
<?php
/* ═══════════════════════════════════════════════════════════════════════
   ESTIBA_TURNO · Motor de cálculo EVADES
   ───────────────────────────────────────────────────────────────────────
   Dado un colaborador y un trimestre, sugiere incremento/descuento por
   competencia a partir de reconocimientos aprobados e incidencias del
   período, más el bono de Autonomía por evaluaciones diarias. No escribe
   nada en la base: solo lee y devuelve sugerencias. Quien persiste es
   api/save_evades.php.
   ═══════════════════════════════════════════════════════════════════════ */

require_once(__DIR__ . '/evades_catalogo.php');

/**
 * Sugerencias para las 10 competencias de un colaborador en un trimestre.
 * Devuelve null si el período no es válido. Cada fila trae:
 *   competencia_key, label, tipo, base(6),
 *   auto_incremento (int|null), auto_descuento (int|null), evidencia[]
 * null en auto_incremento/auto_descuento = "sin evidencia automática"
 * (puede ser porque no hay catálogo para ese lado, o porque sí lo hay
 * pero no se encontró ningún registro en el período).
 */
function evades_calcular_sugerencias($conn, $colaboradorId, $periodo) {
    $rango = evades_periodo_fechas($periodo);
    if (!$rango) return null;

    $catalogo = evades_competencias();
    $resultado = [];

    foreach ($catalogo as $key => $comp) {
        $fila = [
            'competencia_key' => $key,
            'label' => $comp['label'],
            'tipo' => $comp['tipo'],
            'base' => 6,
            'auto_incremento' => null,
            'auto_descuento' => null,
            'evidencia' => [],
        ];

        if ($comp['rec_competencia'] !== null) {
            $inc = evades_incremento_de_reconocimientos($conn, $colaboradorId, $comp['rec_competencia'], $rango);
            $fila['auto_incremento'] = $inc['incremento'];
            $fila['evidencia'] = array_merge($fila['evidencia'], $inc['evidencia']);
        }

        if ($comp['inc_competencia'] !== null) {
            $desc = evades_descuento_de_incidencias($conn, $colaboradorId, $comp['inc_competencia'], $rango);
            $fila['auto_descuento'] = $desc['descuento'];
            $fila['evidencia'] = array_merge($fila['evidencia'], $desc['evidencia']);
        }

        if ($key === 'autonomia') {
            $bono = evades_bono_autonomia($conn, $colaboradorId, $rango);
            if ($bono !== null) {
                $fila['auto_incremento'] = ($fila['auto_incremento'] ?? 0) + $bono['puntos'];
                $fila['evidencia'][] = $bono['evidencia'];
            }
        }

        $resultado[] = $fila;
    }

    return $resultado;
}

/**
 * Incremento sugerido a partir de reconocimientos aprobados de esa
 * competencia en el rango. bueno=+2, excelente/sobresaliente=+4 (se toma
 * el nivel más alto encontrado, no se suman varios reconocimientos).
 */
function evades_incremento_de_reconocimientos($conn, $colaboradorId, $competencia, $rango) {
    $stmt = mysqli_prepare(
        $conn,
        "SELECT id, fecha, impacto FROM reconocimientos
          WHERE colaborador_id=? AND competencia=? AND estado='aprobado'
            AND fecha BETWEEN ? AND ?"
    );
    mysqli_stmt_bind_param($stmt, 'isss', $colaboradorId, $competencia, $rango['inicio'], $rango['fin']);
    mysqli_stmt_execute($stmt);
    $res = mysqli_stmt_get_result($stmt);

    $rows = [];
    $mejorNivel = null;
    while ($row = mysqli_fetch_assoc($res)) {
        $rows[] = $row;
        $nivel = in_array($row['impacto'], ['excelente', 'sobresaliente'], true) ? 4 : 2;
        if ($mejorNivel === null || $nivel > $mejorNivel) $mejorNivel = $nivel;
    }
    mysqli_stmt_close($stmt);

    if (empty($rows)) return ['incremento' => null, 'evidencia' => []];

    $evidencia = array_map(function ($r) {
        return ['tipo' => 'reconocimiento', 'id' => (int)$r['id'], 'fecha' => $r['fecha'], 'impacto' => $r['impacto']];
    }, $rows);

    return ['incremento' => $mejorNivel, 'evidencia' => $evidencia];
}

/**
 * Descuento sugerido a partir de incidencias de esa competencia en el
 * rango: Frecuencia = cantidad (tope 5), Impacto = el más severo
 * presente, cruzados contra evades_matriz_fi().
 */
function evades_descuento_de_incidencias($conn, $colaboradorId, $competencia, $rango) {
    $stmt = mysqli_prepare(
        $conn,
        "SELECT id, fecha, impacto FROM incidencias
          WHERE colaborador_id=? AND competencia=? AND fecha BETWEEN ? AND ?"
    );
    mysqli_stmt_bind_param($stmt, 'isss', $colaboradorId, $competencia, $rango['inicio'], $rango['fin']);
    mysqli_stmt_execute($stmt);
    $res = mysqli_stmt_get_result($stmt);

    $rows = [];
    $ordenImpacto = ['minimo' => 1, 'bajo' => 2, 'moderado' => 3, 'alto' => 4, 'critico' => 5];
    $peorImpacto = null;
    $peorRank = 0;
    while ($row = mysqli_fetch_assoc($res)) {
        $rows[] = $row;
        $rank = $ordenImpacto[$row['impacto']] ?? 0;
        if ($rank > $peorRank) { $peorRank = $rank; $peorImpacto = $row['impacto']; }
    }
    mysqli_stmt_close($stmt);

    if (empty($rows)) return ['descuento' => null, 'evidencia' => []];

    $frecuencia = min(count($rows), 5);
    $matriz = evades_matriz_fi();
    $descuento = $matriz[$frecuencia][$peorImpacto] ?? 0;

    $evidencia = array_map(function ($r) {
        return ['tipo' => 'incidencia', 'id' => (int)$r['id'], 'fecha' => $r['fecha'], 'impacto' => $r['impacto']];
    }, $rows);

    return ['descuento' => $descuento, 'evidencia' => $evidencia];
}

/**
 * Bono Autonomía: +2 si el colaborador tiene >= 5 evaluaciones diarias
 * (evaluacion_desempeno) en el trimestre con promedio de puntaje_total > 38.
 * Devuelve null si no aplica.
 */
function evades_bono_autonomia($conn, $colaboradorId, $rango) {
    $stmt = mysqli_prepare(
        $conn,
        "SELECT COUNT(*) AS n, AVG(puntaje_total) AS prom FROM evaluacion_desempeno
          WHERE colaborador_id=? AND fecha BETWEEN ? AND ?"
    );
    mysqli_stmt_bind_param($stmt, 'iss', $colaboradorId, $rango['inicio'], $rango['fin']);
    mysqli_stmt_execute($stmt);
    $row = mysqli_fetch_assoc(mysqli_stmt_get_result($stmt));
    mysqli_stmt_close($stmt);

    $n = (int)($row['n'] ?? 0);
    $prom = $row['prom'] !== null ? (float)$row['prom'] : null;

    if ($n >= 5 && $prom !== null && $prom > 38) {
        return [
            'puntos' => 2,
            'evidencia' => [
                'tipo' => 'bono_evaluacion_diaria',
                'n' => $n,
                'promedio' => round($prom, 1),
            ],
        ];
    }
    return null;
}
```

```js
  async function exportarPDF(id) {
    const res = await fetch(`${BASE}/api/get_evades.php?id=${Number(id)}`, { cache: 'no-store' });
    const data = await res.json();
    if (!data.success) { toast(data.error || 'No se pudo cargar', 'error'); return; }
    const ev = data.data;
    if (!window.jspdf) { toast('No se pudo cargar el generador de PDF', 'error'); return; }

    try {
      const { jsPDF } = window.jspdf;
      const doc = new jsPDF({ unit: 'pt', format: 'a4', orientation: 'portrait' });
      const W = doc.internal.pageSize.getWidth();
      const NAVY = [15, 76, 129];
      const M = 40;
      let y = 40;

      const LOGO_W = 66, LOGO_H = 40, BANNER_H = 46;
      const bannerX = M + LOGO_W + 12;
      const bannerW = W - M - bannerX;
      doc.setFillColor(...NAVY);
      doc.rect(bannerX, y, bannerW, BANNER_H, 'F');
      doc.setFont('helvetica', 'bold'); doc.setFontSize(11); doc.setTextColor(255, 255, 255);
      doc.text('EVALUACIÓN DE DESEMPEÑO INDIVIDUAL — TALLY 2026', bannerX + bannerW / 2, y + 15, { align: 'center' });
      doc.setFont('helvetica', 'bold'); doc.setFontSize(9.5);
      doc.text('SISTEMA EVADES', bannerX + bannerW / 2, y + 27, { align: 'center' });
      doc.setFont('helvetica', 'normal'); doc.setFontSize(8.5);
      doc.text(`Cargo: Asistente de Estiba | Período: ${ev.periodo}`, bannerX + bannerW / 2, y + 38, { align: 'center' });
      if (LOGO_B64) { try { doc.addImage(LOGO_B64, 'PNG', M, y + (BANNER_H - LOGO_H) / 2, LOGO_W, LOGO_H); } catch (e) {} }
      y += BANNER_H + 14;

      doc.autoTable({
        startY: y, theme: 'grid', margin: { left: M, right: M },
        styles: { fontSize: 9, cellPadding: 5, textColor: [17, 24, 39] },
        columnStyles: { 0: { fontStyle: 'bold', fillColor: [219, 234, 254], cellWidth: 110 }, 2: { fontStyle: 'bold', fillColor: [219, 234, 254], cellWidth: 110 } },
        body: [
          ['Nombre completo', { content: ev.colaborador_nombre, colSpan: 3 }],
          ['Cargo', ev.colaborador_cargo || 'Asistente de Estiba', 'Período', ev.periodo],
          ['Evaluador', ev.coordinador_nombre, 'Fecha', ev.fecha_evaluacion],
        ],
      });
      y = doc.lastAutoTable.finalY + 12;

      const filaTabla = c => {
        const meta = COMPETENCIAS[c.competencia_key] || { label: c.competencia_key };
        return [meta.label, c.base, `+${c.incremento_final}`, `-${c.descuento_final}`, c.puntaje_final];
      };
      const secA = ev.competencias.filter(c => c.tipo === 'conductual');
      const secB = ev.competencias.filter(c => c.tipo === 'operativa');
      const subtotal = arr => arr.reduce((s, c) => s + c.puntaje_final, 0);

      doc.autoTable({
        startY: y,
        head: [['SECCIÓN A · CONDUCTUALES', 'Base', 'Incr.', 'Desc.', 'Final']],
        body: [...secA.map(filaTabla), [{ content: 'SUBTOTAL A', styles: { fontStyle: 'bold' } }, '', '', '', { content: `${subtotal(secA)} / 50`, styles: { fontStyle: 'bold' } }]],
        theme: 'grid', margin: { left: M, right: M },
        styles: { fontSize: 9, cellPadding: 6 },
        headStyles: { fillColor: NAVY, textColor: 255, fontStyle: 'bold' },
        columnStyles: { 1: { halign: 'center', cellWidth: 40 }, 2: { halign: 'center', cellWidth: 40 }, 3: { halign: 'center', cellWidth: 40 }, 4: { halign: 'center', cellWidth: 50 } },
      });
      y = doc.lastAutoTable.finalY + 10;

      doc.autoTable({
        startY: y,
        head: [['SECCIÓN B · OPERATIVAS', 'Base', 'Incr.', 'Desc.', 'Final']],
        body: [...secB.map(filaTabla), [{ content: 'SUBTOTAL B', styles: { fontStyle: 'bold' } }, '', '', '', { content: `${subtotal(secB)} / 50`, styles: { fontStyle: 'bold' } }]],
        theme: 'grid', margin: { left: M, right: M },
        styles: { fontSize: 9, cellPadding: 6 },
        headStyles: { fillColor: NAVY, textColor: 255, fontStyle: 'bold' },
        columnStyles: { 1: { halign: 'center', cellWidth: 40 }, 2: { halign: 'center', cellWidth: 40 }, 3: { halign: 'center', cellWidth: 40 }, 4: { halign: 'center', cellWidth: 50 } },
      });
      y = doc.lastAutoTable.finalY + 12;

      doc.setFillColor(...NAVY);
      doc.rect(M, y, W - M * 2, 26, 'F');
      doc.setFont('helvetica', 'bold'); doc.setFontSize(11); doc.setTextColor(255, 255, 255);
      doc.text(`PUNTAJE TOTAL: ${ev.puntaje_total} / 100`, M + 10, y + 17);
      doc.text(ev.clasificacion, W - M - 10, y + 17, { align: 'right' });
      y += 26 + 14;

      const bloqueTexto = (titulo, texto) => {
        doc.setFont('helvetica', 'bold'); doc.setFontSize(9.5); doc.setTextColor(17, 24, 39);
        doc.text(titulo, M, y); y += 12;
        const lines = doc.splitTextToSize(texto || '—', W - M * 2);
        doc.setFont('helvetica', 'normal'); doc.setFontSize(9); doc.setTextColor(55, 65, 81);
        doc.text(lines, M, y); y += lines.length * 11 + 12;

      bloqueTexto('Fortalezas observadas', ev.fortalezas);
      bloqueTexto('Aspectos a mejorar', ev.aspectos_mejora);
      bloqueTexto('Plan de acción para el próximo trimestre', ev.plan_accion);

      const safeName = (ev.colaborador_nombre || 'evades').replace(/[^a-z0-9]+/gi, '_');
      doc.save(`evades_${ev.periodo}_${safeName}.pdf`);
    } catch (e) {
      toast('No se pudo generar el PDF', 'error');
    }
  }

  $('evTbody').addEventListener('click', e => {

    exportarPDF(b.dataset.id);
  });
  $('evViewPdf').addEventListener('click', e => exportarPDF(e.currentTarget.dataset.id));
```
